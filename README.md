# Каталог участников проекта

## Описание проекта

Это веб-приложение, в котором можно посмотреть список участников проекта и добавить нового участника. Для каждого участника отображается имя, электронная почта и пожелание.

Проект создан с использованием React для Frontend и Python Flask для Backend. Данные участников хранятся в базе данных SQLite.

## Используемые технологии

**Frontend:**
- React
- JavaScript
- HTML
- CSS
- Vite

**Backend:**
- Python
- Flask
- Flask-CORS
- SQLite

## Структура проекта

- `Frontend` — клиентская часть приложения.
- `Backend` — серверная часть приложения и работа с базой данных.

## Как запустить проект

Для запуска понадобятся установленный Python и Node.js.

### 1. Запуск Backend

Откройте терминал в папке проекта и выполните команды:

```bash
cd Backend
```

При необходимости установите зависимости:

```bash
pip install flask flask-cors
```

Запустите сервер:

```bash
python app.py
```

После запуска Backend будет доступен по адресу:

http://localhost:5000

### 2. Запуск Frontend

Откройте **второй терминал** и выполните:

```bash
cd Frontend
```

Установите необходимые зависимости:

```bash
npm install
```

Запустите приложение:

```bash
npm run dev
```

После этого Vite покажет адрес, по которому можно открыть приложение в браузере (обычно http://localhost:5173).

**Важно:** для корректной работы приложения должны быть запущены одновременно и Backend, и Frontend.

## Возможности приложения

- Просмотр списка участников.
- Добавление нового участника через форму.
- Ввод имени, электронной почты и пожелания.
- Сохранение данных в базе SQLite.
- Автоматическое обновление списка после добавления участника.
